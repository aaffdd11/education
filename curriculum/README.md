# 三年级科学课程（约 9 岁）

面向约 9 岁、小学三年级的科学启蒙课程。全中文。学科：**物理 / 化学 / 数学**。共 **24 个单元**。

## 三层结构

| 层级 | 名称 | 职责 |
|------|------|------|
| **L1** | 课程内容 | 学科、单元、课时目标、材料概要、先修关系 |
| **L2** | 难度与知识细节 | 基础 / 进阶 / 拓展；知识点、误区、步骤、验收 |
| **L3** | 互动与视频 | 互动规格、视频脚本；示范 + 可扩展槽位 |

## 难度说明（L2）

| 级别 | 定位 | 孩子能做什么 |
|------|------|--------------|
| 基础 | 观察与口语概念 | 说出「是什么」、完成安全观察 |
| 进阶 | 记录与简单推理 | 用数据比较、说出「有什么不同」 |
| 拓展 | 变量与解释 | 控制一个变量、解释「为什么」 |

建议路径：先过「基础」验收，再进「进阶」；「拓展」可选。

## L3 现状

- 已提供统一 [schema](L3/schema.md)
- 示范 3 个单元：物理 U01（力与运动）、化学 U02（溶解）、数学 U01（测量）
- 其余单元可按同一 schema 继续补互动与视频

## 使用建议

1. 家长/老师先看 `L1/总览.md` 选单元顺序  
2. 上课用对应 `L2` 文件，按难度推进  
3. 需要屏幕互动或视频时，对照 `L3` 示范扩展
