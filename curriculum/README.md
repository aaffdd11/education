## 难度说明（L2）

| 级别 | 定位 | 孩子能做什么 |
|------|------|--------------|
| 基础 | 观察与口语概念 | 说出「是什么」、完成安全观察 |
| 进阶 | 记录与简单推理 | 用数据比较、说出「有什么不同」 |
| 拓展 | 变量与解释 | 控制一个变量、解释「为什么」 |

建议路径：先过「基础」验收，再进「进阶」；「拓展」可选。
