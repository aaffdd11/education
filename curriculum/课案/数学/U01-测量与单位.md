# 课案 · 数学 U01 · 测量与单位

> **趣味标题**：给世界标上「多长、多重」  
> **对应 L1**：`L1/数学/U01-测量与单位.md`  
> **90 秒脚本**：`L3/视频/数学-U01-测量与单位.md`

## 一句话目标

会从 0 对齐量长度，并带单位说话。

## 开场（大人怎么说）

「『好长』不够。今天我们给世界贴上数字标签。」

## 核心演示（约 10–15 分钟）

1. 错误示范从 1 起量，再纠正到 0。
2. 量橡皮/书，写数字+厘米。
3. 量杯读 100 毫升，平视。
4. 可选：100 厘米＝1 米。

## 孩子主任务

孩子独立正确量一件物品，并写出带单位的结果。

## 追问（选 1–2 个）

- 量教室选什么工具？
- 为什么有时要量两次？

## 收尾金句

> 从 0 开始，带着单位说话。

## 安全

水远离电器。

## 课堂时间建议（40–45 分钟版）

| 时段 | 内容 |
|------|------|
| 0–5 分 | 开场钩子 + 先猜 |
| 5–20 分 | 核心演示（一起做） |
| 20–35 分 | 孩子主任务 |
| 35–45 分 | 追问 + 用自己的话复述金句 |

多日观察课（生锈/晶体）：当日完成布置与记录方法，后续每天 2–3 分钟打卡。
