# 力学推导人生 · 总映射

适用：物理力学三讲（U01 力与运动 · U02 重力 · U03 简单机械）  
对象：约 9 岁。先做实验，再照镜子——**不说教，用小车说话**。

## 主映射

| 力学 | 孩子说法 | 人生 |
|------|----------|------|
| 推力 | 推一把，车才动 | 真的开始做 |
| 阻力 / 摩擦 | 毛巾拖后腿 | 懒、怕、打扰、坏习惯 |
| 短暂的推 | 推一下就松手 → 停 | 热一会儿就放弃 |
| 持续的推 | 一直轻轻推 → 继续 | 每天一点点 |
| 方向 | 往哪推，往哪走 | 目标要对 |
| 重力 | 总有往下的拉 | 想偷懒、想放弃 |
| 杠杆 / 斜面 | 方法对，更省劲 | 找方法、借工具、请人教 |

## 总金句

> 只推一下，会停下；持续地推，才会继续。  
> 阻力不是敌人，是提醒你：要不要再推一把。

## 课堂顺序（加长版）

1. 物理实验（看见）  
2. 用孩子的话总结力学  
3. **人生镜像**（把小车换成自己）  
4. 一句行动：今天持续推什么？

脚本时长：力学三讲改为约 **3 分钟**（可录 2.5–3.5 分）。
