# education

三年级（约 9 岁）科学课程内容仓库。全中文。

## 快速开始

课程主体在 [`curriculum/`](curriculum/README.md)：

| 层级 | 内容 |
|------|------|
| L1 | 24 单元课程骨架（物理/化学/数学各 8） |
| L2 | 每单元基础 / 进阶 / 拓展知识细节 |
| L3 | 互动与视频规范 + 3 个示范单元 |

从 [`curriculum/L1/总览.md`](curriculum/L1/总览.md) 开始浏览。

## 生成脚本

如需按数据源重新生成 L1/L2 文件：

```bash
python3 scripts/generate_curriculum.py
```
